## 常见问题

我的数据存储在哪里？

所有数据都保存在你的设备上。Syntax 没有服务器，也没有云同步。你的训练文件是纯文本格式，存储在应用的本地目录中。

需要 AI API 密钥吗？

不需要。AI 教练是完全可选的功能。应用在没有 AI 的情况下也能完整运行。如果你想使用 AI 功能，需要自备来自 OpenAI、Anthropic 或 Google 的 API 密钥。

可以导出训练记录吗？

可以。你的训练记录是纯 Markdown 文件。开启文件共享后，可以通过"文件"应用访问它们。

支持 Apple Watch 吗？

Syntax 通过 Apple Health 读取训练和心率数据，其中包含来自 Apple Watch 的数据。目前还没有独立的 Watch 应用。
